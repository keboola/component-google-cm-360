[Google Campaign Manager 360](https://support.google.com/campaignmanager/answer/2709362?hl=en) orchestrates digital advertising campaigns, enabling precise ad placements across multiple channels.

This connector enables retrieval of Campaign Manager 360 reports **across multiple Ad Accounts**. It supports four modes:

1. **Export metadata** – export CM360 account metadata into a separate table.
2. **Define reports in the UI** – define report dimensions, metrics, and type directly in the Keboola UI.
3. **Existing report IDs** – run pre-existing reports that share the same structure across multiple accounts. Reports can be created via the [CM360 Report Builder](https://www.google.com/analytics/dfa/).
4. **Report template** – select an existing report definition as a template and run it across multiple selected accounts. Reports can be created via the [CM360 Report Builder](https://www.google.com/analytics/dfa/).
